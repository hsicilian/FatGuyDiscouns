# Seed guidance

Use seed records that cover these scenarios:

- Pending customer awaiting approval
- Approved customer with active balance cycle
- Customer with overdue cycle and existing credit
- Products in active, low-stock, and out-of-stock states
- Shipment request in progress
- Calendar events across multiple live-sale platforms
- Notifications for claims, approvals, shipment requests, low stock, and restock requests

This seed pass should be implemented after the Supabase client and server actions are added.
